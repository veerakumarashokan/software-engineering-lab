# Software Engineering Lab

Software engineering lab focused on programming fundamentals, software development concepts, practical exercises, and project-based learning.

## Objectives

- Learn and practice programming languages, starting with C and C++.
- Strengthen problem-solving skills and computational thinking.
- Maintain a structured journal of learning progress and practical work.
- Document technical concepts, notes, and key takeaways.
- Apply programming knowledge through hands-on projects.

## Areas of Practice

- **C Programming:** Fundamentals, control structures, functions, pointers, and memory management.
- **C++ Programming:** Object-oriented programming, data structures, and algorithms.
- **Journal:** Learning progress, practical activities, challenges, and reflections.
- **Notes:** Programming concepts, syntax references, explanations, and useful resources.
- **Projects:** Practical applications and experiments developed throughout the learning journey.
