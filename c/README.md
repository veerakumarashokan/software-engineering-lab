# C Programming

Practical C programming focused on language fundamentals, problem-solving, memory management, and structured programming through hands-on exercises.

## Objectives
- Learn C syntax, data types, variables, and operators.
- Practice conditional statements, loops, and functions.
- Understand arrays, strings, pointers, and memory management.
- Develop logical reasoning through programming exercises.
- Practice compiling, debugging, and executing C programs.

## Topics Covered
- Fundamentals and basic input/output
- Operators and control structures
- Functions and recursion
- Arrays and strings
- Pointers and memory management
- Structures, unions, and enumerations
- File handling
- Data structures and algorithms

## Tools and Technologies
- Visual Studio Code
- GCC Compiler
- Git and GitHub

## Purpose
This directory contains C programs, practical exercises, and implementations developed while learning and strengthening programming fundamentals.
